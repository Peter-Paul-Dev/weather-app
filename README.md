The goal of this project is to create a weather app that displays weather information, such as temperature, heat index, whether it's sunny or rainy, and more. It should dynamically change its appearance depending on the whether (eg. blue background when the sky is clear, dark blue when it's rainy, and yellow/orange when it's hot).

The primary objective of this project is to make me learn how to retrieve data using APIs and use asynchronous functions to actually do something with them.
